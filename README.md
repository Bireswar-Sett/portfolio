# Bireswar Sett — Minimal Portfolio

Static, responsive portfolio built with HTML, CSS, and a tiny IntersectionObserver reveal effect. No build tools or dependencies required.

## Publish on GitHub Pages

1. Create a repository named `portfolio` on GitHub.
2. Upload `index.html`, this `README.md`, and the `assets/` directory.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. When deployed, the site URL will usually be `https://Bireswar-Sett.github.io/portfolio/`.
